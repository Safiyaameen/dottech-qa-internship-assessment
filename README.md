## About This Assessment

This repository contains my QA & Software Testing internship assessment prepared for DotTech Software.

The assessment is based on the User Login and Product Search feature specification provided by DotTech Software.

The work focuses on requirements-based manual testing and includes:

* Test Plan
* Test Cases
* Bug Reports
* Candidate Questions

---

## Features Covered

### 1. User Login

The testing covers:

* Valid and invalid login attempts
* Login error handling
* Three consecutive failed login attempts
* Five-minute account lock
* Email format validation
* Minimum eight-character password requirement
* Forgot Password navigation

### 2. Product Search

The testing covers:

* Product search
* 500 ms debounce behaviour
* Search result information
* No-results behaviour
* Case-insensitive searching
* Leading and trailing spaces
* Clearing search and restoring the full product list

---

## Testing Approach

A requirements-based manual testing approach was used.

The supplied feature specification was reviewed first, then testable requirements and test conditions were identified. Test cases were created to cover functional, positive, negative, boundary, edge, timing and state/sequence scenarios.

---

## Important Testing Note

No executable application or dedicated test environment was provided with the assessment.

Therefore:

* The test cases represent planned test coverage based on the supplied requirements.
* The three bug reports are hypothetical sample defects that could be identified during actual execution.
* No actual defect discovery is being claimed.
